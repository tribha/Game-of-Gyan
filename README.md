# 🎮 Game of Gyan

**Game of Gyan** is a cutting-edge, gamified coding learning platform designed to turn the journey of mastering programming into an epic quest. By combining educational content with game mechanics, we make learning to code engaging, competitive, and rewarding.

---

## 🛡️ Project Vision
To empower the next generation of "Code Warriors" through an interactive environment where knowledge is the ultimate weapon. We aim to break down complex concepts in JavaScript, Python, SQL, Java, and C++ into digestible, mission-based levels.

---

## ✨ Key Features

### 🗺️ Learning Paths (Courses)
- **Comprehensive Tracks**: Structured curriculum for JavaScript, Python, Java, C++, and SQL.
- **Progressive Levels**: Unlock new challenges as you master foundational concepts.
- **Interactive Exercises**: A mix of Multiple Choice Questions (MCQs) and hands-on Code Challenges.

### ⚡ Daily Challenges
- **Daily Missions**: A new challenge every day to keep your "Coding Streak" alive.
- **Global Competition**: Compete with the entire community on the leaderboard.

### 🚀 Expert Level
- **Real-world Scenarios**: Advanced challenges focused on debugging and complex logic.
- **"Find the Error" Mode**: Sharpen your eye for bugs in professional-grade code snippets.
- **Helper Route**: Navigate through day-in-the-life coding scenarios.

### 🤝 Social Hub
- **Forging Alliances**: Search for other learners and send friend requests.
- **Competitive Spirit**: View your friends' XP, levels, and streaks.
- **Collaborative Growth**: Rise through the ranks together.

### 🏆 Achievement System
- **Earn Badges**: Collect digital awards for milestones like "First Code" or "JS Novice."
- **Certificates of Completion**: Receive professional, verifiable certificates upon finishing a course track.
- **XP & Levels**: Accumulate Experience Points (XP) to level up your profile and unlock elite status.

---

## 🛠️ Tech Stack

- **Frontend**: [Next.js 15](https://nextjs.org/) (App Router), [React 19](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [ShadCN UI](https://ui.shadcn.com/), [Lucide Icons](https://lucide.dev/)
- **Backend & Auth**: [Firebase](https://firebase.google.com/) (Firestore, Authentication)
- **AI Integration**: [Google Genkit](https://github.com/firebase/genkit) (for Smart Hint System and Code Simulation)
- **Language Support**: JavaScript, Python, Java, C++, SQL, HTML/CSS

## 🚀 Getting Started

### Prerequisites
- Node.js (Latest LTS)
- NPM or PNPM

### Installation
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-repo/game-of-gyan.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Set up Environment Variables**:
    Create a `.env` file and add your Firebase configuration.
4.  **Run the development server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:9002](http://localhost:9002) in your browser.

## 📁 Project Structure

- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable UI components (Common, Game, Dashboard, Friends).
- `src/firebase`: Firebase configuration, hooks, and utility functions.
- `src/ai`: Genkit flows for smart hints and AI-powered code execution.
- `src/lib`: Mock data, challenge definitions, and helper utilities.
- `docs/`: Backend specifications and IR representations.
